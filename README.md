# Фінальний проєкт RDB — Pandemic

## Опис проєкту

Фінальний проєкт курсу **Relational Databases (RDB)**.

Мета проєкту — практичне застосування SQL для створення та нормалізації бази даних, аналізу статистичних даних про інфекційні захворювання та роботи з вбудованими й користувацькими функціями MySQL.

## Технології

- MySQL
- MySQL Workbench
- SQL
- Git / GitHub

## Виконані завдання

### Завдання 1. Створення бази даних

- Створено схему `pandemic`.
- Імпортовано дані до таблиці `infectious_cases` за допомогою Table Data Import Wizard.
- Перевірено кількість імпортованих записів — **7271**.

### Завдання 2. Нормалізація даних до 3НФ

- Створено таблицю `entities` для зберігання унікальних комбінацій `Entity` та `Code`.
- Створено таблицю `infectious_cases_normalized` для зберігання статистики захворювань.
- Реалізовано зв'язок між таблицями за допомогою зовнішнього ключа `FOREIGN KEY`.
- Виконано перенесення та перевірку даних.

**Результати:**

- `entities` — 195 записів.
- `infectious_cases_normalized` — 7271 запис.

### Завдання 3. Аналіз статистичних даних

Для показника `Number_rabies` обчислено:

- Середнє значення (`AVG`).
- Мінімальне значення (`MIN`).
- Максимальне значення (`MAX`).
- Суму значень (`SUM`).

Результати згруповано за країнами, відсортовано за середнім значенням у порядку спадання та обмежено десятьма записами.

### Завдання 4. Робота з датами

За допомогою вбудованих функцій MySQL:

- `MAKEDATE()` — сформовано дату першого січня відповідного року.
- `CURDATE()` — отримано поточну дату.
- `TIMESTAMPDIFF()` — обчислено різницю між датами в роках.

### Завдання 5. Створення власної функції

Створено користувацьку функцію `calculate_years_difference()`.

Функція приймає рік як параметр та повертає різницю між поточною датою і першим січня зазначеного року.

Роботу функції перевірено на даних таблиці `infectious_cases_normalized`.

## Виконання проєкту

1. Відкрити MySQL Workbench.
2. Створити схему `pandemic`.
3. Імпортувати вихідний набір даних у таблицю `infectious_cases` через Table Data Import Wizard.
4. Відкрити файл `pandemic_final_project.sql`.
5. Послідовно виконати SQL-команди для створення нормалізованих таблиць, аналізу даних та перевірки функцій.

**Примітка:** команди створення таблиць, заповнення даних і створення функції призначені для початкового виконання. Повторний запуск без попереднього очищення відповідних об'єктів може спричинити помилки або дублювання записів.
